# MiniPac OOP — LevelLoader

Учебная консольная игра на C++17 для Windows.

## Что изменилось

Карта больше не зашита в `Level.cpp`. Она загружается из UTF-8 файла `level.txt` через отдельный класс `LevelLoader`.

`level.txt` можно менять без перекомпиляции игры.

Символ `P` обозначает старт игрока. При загрузке Level заменяет `P` обычным пробелом.

Пример:

```text
╔══════════╗
║          ║
║    P     ║
║          ║
╚══════════╝
```

Уровень должен быть прямоугольным: все строки обязаны иметь одинаковую ширину.

## Основные классы

- `Game` — главный игровой цикл и перезапуск раунда.
- `Level` — игровое состояние уровня, проходимость и трава.
- `LevelLoader` — чтение и проверка UTF-8 файла уровня.
- `Player` — игрок.
- `NPC` — преследователь и BFS-поиск пути.
- `Input` — клавиатура.
- `Renderer` — Windows-консоль и цвета.

## Сборка MinGW g++

```powershell
.\build_g++.bat
```

или:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp Game.cpp Level.cpp LevelLoader.cpp Player.cpp NPC.cpp Input.cpp Renderer.cpp -o MiniPac.exe
.\MiniPac.exe
```

Важно: `level.txt` должен находиться в рабочей папке, из которой запускается `MiniPac.exe`.

## Интересная возможность

При GAME OVER новый `Level` создаётся заново и `level.txt` перечитывается. Поэтому можно отредактировать файл уровня во время игры, проиграть раунд и увидеть новую карту без повторной компиляции.
